A cloud infrastructure automation project built collaboratively with an engineering team to demonstrate Infrastructure as Code, CI/CD, automated drift detection, and self-healing infrastructure principles.

The platform provisions and manages AWS infrastructure using Terraform, with separate development and production environments and automated CI/CD workflows.

**Key Features**

* Infrastructure as Code using Terraform
* AWS EC2 infrastructure provisioning
* S3 bucket management
* Separate Development and Production environments
* Reusable Terraform modules
* Remote Terraform state management
* Infrastructure drift simulation and detection
* Automated CI/CD using GitHub Actions
* Infrastructure validation and deployment workflows
* IAM configuration and infrastructure security
* Automated infrastructure recovery / self-healing workflows
* Modular and reproducible infrastructure architecture

**Tech Stack**
Terraform, AWS, EC2, S3, IAM, GitHub Actions, CI/CD, Linux, Bash, Infrastructure as Code
